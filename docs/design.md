# Reference identity

The reference uses a white surface, D-DIN typography and one red accent
(`#e82127`). A simple five-point star identifies Starchat in the header and
favicon. The conversation remains the main action; technical help is available
when a visitor asks for it.

Regular text and bold headings use the engine's self-hosted D-DIN files under
the SIL Open Font License, included in the package. These files match the
SKYYWARE website's D-DIN assets. The text wordmark stays accessible and uses the
same font. The star is original vector geometry, not a copied company mark.

Four suggested questions form two columns on larger screens and one column
below 480 pixels. Controls keep a visible background or color change for
keyboard focus without outlines. Header, conversation and legal footer share
the same width.

Review desktop, 393-pixel and 320-pixel layouts in the native browser. Check
keyboard focus, contrast, tap targets, restored conversations, legal sections
and long content as well as the initial screen.
