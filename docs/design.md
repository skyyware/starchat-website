# Reference identity

The reference uses a white surface, restrained typography and a single blue
accent. It should feel approachable for an individual, company or public service.
The conversation remains the main action. Technical help is a contextual next
step, rather than the starting point for every visitor.

The public reference self-hosts Inter 4.1 under the included SIL Open Font
License. Medium headings, regular body text and generous spacing keep the
interface readable. No proprietary font payload is distributed here.

- [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1)
- [Included Inter license](../public/branding/inter-license.txt)

The eight-point star is original vector geometry. Cardinal, diagonal and inner
radii use 34, 21 and 13 units on an 89-unit canvas, consecutive Fibonacci values
that approximate the golden ratio. Rounded valleys and an eleven-degree rotation
give it a less mechanical silhouette. The wordmark uses outlined Inter Medium;
the favicon uses the same star with a light/dark color adaptation. It is not a
redrawn third-party mark. Similarity review is visual, not a trademark clearance.
